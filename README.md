## 🧑‍🔧 About Me

By day I make warehouse robots and conveyors talk to each other — WCS/PLC, WAMAS, Siemens, Libiao Robotics.  
By night I learn to talk to the hardware myself.

🎯 **Mission:** Master the full embedded stack — hardware → firmware → UI → mesh networking  
🔭 **End goal:** Local-first smart home ecosystem, owned end-to-end  
📚 **Reading:** *Making Embedded Systems* · *Mastering FreeRTOS* · *Fast & Effective Embedded Systems Design*

> MicroPython · ESP32-S3 · ENV III · Open-Meteo API

Indoor/outdoor weather station on a 320×240 touch display. Five navigable screens, async architecture, stale-while-revalidate weather cache, sleep mode, persistent settings.
